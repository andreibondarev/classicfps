# Custom spray

`rushing_andrei.png` is the generated transparent graffiti decal for
`@rushing_andrei`. Created with the built-in image-generation tool; original
2172 × 724 PNG preserved. Godot imports a mipmapped maximum-1024-pixel texture.
The in-game decal is 0.96 × 0.32 world units. Press T within 1.28 units of a flat
static surface. There is a 10-second per-player cooldown and a 32-spray limit.
Sprays clear next round; server snapshots replicate them to late joiners too.
This build uses one bundled spray, not arbitrary player-uploaded images.

## Generation prompt

Use case: stylized-concept. Asset type: transparent PNG spraypaint decal for a classic tactical FPS game. Create a cool, original hand-painted graffiti tag containing exactly the Twitter handle "@rushing_andrei", spelled @ r u s h i n g _ a n d r e i. Make the entire handle very legible, with energetic chunky graffiti lettering, strong dark outline, contrasting bright painted highlights, modest paint drips and aerosol flecks. Center the complete tag with clear margins, wide horizontal composition, front-on flat decal with no perspective distortion. Genuine transparent alpha background; no wall, scene, checkerboard, rectangular backing, extra slogans, extra text, watermark, or social-media logo. Prioritize readable lettering at in-game texture size. All characters including the @ and underscore must be present and unobscured.
